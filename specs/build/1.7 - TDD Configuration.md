# 1.7 — TDD Configuration

**Epic**: Make TDD enforcement configurable per workspace

## Goal

Allow workspaces to opt out of mandatory inline TDD. When disabled, the Code Planner is instructed to create separate test follow-up tasks rather than requiring them inline with implementation. The submission gate and reviewer do not enforce test file presence.

## Motivation

ADR-0007 made TDD mandatory for MAS. While this is the right default, frontend and UI-heavy teams find it constraining. This epic adds a workspace-level toggle that preserves TDD as default while enabling alternative workflows.

## Success Criteria

- Existing workspaces (no `tdd_enabled` field) behave identically to before
- `liza init --no-tdd` creates a workspace where coders are not required to include test files
- Code Planner creates separate test tasks when TDD is disabled
- Submission gate and Code Reviewer respect the config setting
